# WindIme 改进建议

更新日期：2026-07-24

本文记录当前版本后续改进方向。实施原则是优先保证实体键盘输入可靠性、用户数据安全和低配设备体验，再扩展词库及联网能力。

## 1. 701KC 真机回归

建立每次发布前的固定回归清单：

- 单行输入框的完成、搜索、发送、下一项等编辑器动作。
- 多行输入框的换行。
- 中文候选、拼音读音层、英文 T9 和 Multi-tap 的确认行为。
- 校准后确认键在候选条、符号和定型文面板中的行为。
- 输入框快速切换、多应用切换、来电、锁屏和解锁。
- 共享 BACK/退格从删除、关闭输入法到恢复系统返回的完整流程。
- 快速连按和长按产生的重复事件。
- Rime 后台部署期间输入，以及部署完成后的后端切换。

## 2. 按键校准管理

实施状态：已完成首版多配置管理。

当前采用一个只读系统默认配置和四个用户配置槽。用户可切换、查看、校准、重命名和删除配置；旧版单一 `user_keymap.json` 会迁移到用户配置 1。校准完成后填写配置名称并保存启用，跳过项目会保留目标配置原映射，空槽则继承系统默认。

输入法支持标准 Android `KEYCODE_MENU`，也允许在用户配置中校准 `SHOW_QUICK_MENU`。当翻盖机的 Softkey Guide 显示 MENU、但底层发送厂商 KeyCode/ScanCode 时，用户可直接捕获该按键。映射只在 WindIme 输入会话中生效，不改变邮箱键等软键在其他场景的用途。快捷菜单保留映射配置、系统输入法选择、模式循环和 WindIme 设置；模式循环可直接勾选中文/英文 T9、Multi-tap 与数字模式，并保证至少启用一个。

校准只处理真正因机型而异的功能键：中英切换、符号表、快捷菜单和退格。标准数字键、方向键和确认键由内置映射保障，不允许改绑，以免破坏向导操作。

建议能力：

- 标准 OK/ENTER 跳过当前校准项。
- 标准方向键不参与捕获。
- 支持取消且不保存本次修改。
- 支持重试当前步骤和返回上一步。
- 完成前显示完整映射摘要，并由用户确认保存。
- 按键设置页显示当前映射来源和各功能的实际 KeyCode/ScanCode。
- 提供明确的恢复默认映射入口。
- 阻止同一 KeyCode 或 ScanCode 重复绑定。
- 新映射在下一次输入会话自动生效；条件允许时通知运行中的输入法立即重载。

## 3. 候选翻页与小屏显示

实施状态：已完成（2026-07-24）。

- 候选超过可视宽度时允许左右键连续访问。
- 显示候选页码或当前位置。
- 第二层拼音和第三层词候选分别保存焦点。
- 候选刷新后校正焦点，禁止提交旧索引。
- 长词显示可省略，但提交内容必须保持完整。
- 在 701KC 真机检查三行候选高度和长文本可读性。

## 4. 现有设置落地

实施状态：已完成（2026-07-24）。

- 实现英文句首自动大写。
- 实现震动、声音、无反馈三档按键反馈。
- 避免与系统按键音或震动重复触发。
- 根据真机体验调整 Multi-tap 默认间隔和可选范围。

## 5. 用户数据可靠性

实施状态：已完成（2026-07-24）。

- 用户词典和定型文使用临时文件加原子替换写入。
- 增加用户词典及定型文导入、导出。
- 对重复词、空内容和过长内容进行校验。
- JSON 损坏时保留原文件并提供恢复路径。
- 重置页分别提供清除 Rime 学习、用户词典、定型文、按键映射和全部设置。
- 验证定型文编辑、保存和复制按钮不会互相覆盖。

## 6. 英文 T9 词库

使用已经内置的 `en + en_ext` 源数据，在构建阶段生成紧凑 T9 索引，替换当前小型英文词表。运行时不扫描 YAML，以控制首次输入延迟和内存占用。

## 7. Rime 生命周期和可观测性

实施状态：已完成（2026-07-24）。

- 明确 native Rime 初始化、部署、同步和退出的唯一所有者。
- 避免 Service 重建后出现重复 maintenance 会话。
- 后台部署期间不得贸然关闭 native 状态。
- 为每次初始化和部署增加会话编号及结构化日志。
- 部署失败后保持 Java fallback 可用，并提供安全重试。

## 8. ABI 与 JNI 构建

- 在可可靠生成对应原生库后再增加 `arm64-v8a`。
- 固定 Trime、librime、依赖库和 NDK 版本。
- 保存完整构建脚本、编译参数和产物 SHA-256。
- 保证发布二进制对应的源码和构建说明可获得。

## 9. 版本和发布流程

- 以 `app/build.gradle` 为唯一版本来源。
- 发布时自动生成 APK 文件名、版本说明、Git tag 和词库哈希记录。
- 发布检查包含构建、单元测试、许可证、源码、真机回归和数据升级验证。

## 10. 联网扩展词库

Tencent 等扩展词库暂不优先。实现前必须解决网络权限、剩余空间、断点和失败重试、SHA-256 校验、部署回滚、删除恢复及许可证源码提供问题。当前阶段优先完善离线输入、按键可靠性、候选翻页和数据安全。
