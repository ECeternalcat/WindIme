Garaho T9 IME 模式状态机与极简设置规范

本文档对标日系经典翻盖机输入法 iWnn IME 的极简设计哲学，针对零触摸屏（0-Touch）硬件环境，定义了单键模式循环状态机与系统设置项菜单树。

1. 模式切换状态机 (Mode State Machine)

由于物理翻盖机按键资源极度紧张，本方案将 “语言切换” 与 “输入模式（T9 联想 / Multi-tap 直通）” 融合为一个单键触发的状态机循环。

1.1 全量循环链条 (Full Cycle)

默认状态下，按下自定义的 [MODE_TOGGLE]（语言/模式切换键）时，输入法将在以下 5 个状态间顺序循环：

┌──────────────┐     短按切换     ┌──────────────┐     短按切换     ┌──────────────┐
│  [1] 中文 T9 │ ────────────────► │ [2] 中文 M-Tap│ ────────────────► │  [3] 英文 T9 │
└──────▲───────┘                   └──────────────┘                   └──────┬───────┘
       │                                                                     │ 短按切换
       │                         短按切换                             ▼
┌──────┴───────┐                   ┌──────────────┐                   ┌──────────────┐
│  [5] 数字123 │ ◄──────────────── │ [4] 英文 M-Tap│ ◄──────────────── │ [4] 英文 M-Tap│
└──────────────┘                   └──────────────┘                   └──────────────┘


[1] 中文 T9：输入数字键触发拼音联想与词库检索（如按下 2-3-2-6 检索 chao / chen 等候选词）。

[2] 中文 Multi-tap：多次点击数字键依次切换单个拼音字母（如连续按 2 键 3 次输出 c），用于精准敲出生僻字拼音或拼音首字母。

[3] 英文 T9：根据英文词库进行单词概率预测。

[4] 英文 Multi-tap：经典的 a-b-c 循环直通模式，专用于密码、网址、英文缩写输入。

[5] 数字 123：按键直接输出物理数字 0-9。

1.2 可裁切模式配置 (Customizable Mode Loop)

为了避免用户每次切换都要按 4-5 次按键，系统允许用户在设置中选择性勾选需要参与循环的模式。

常见优化组合示例：

极简模式（推荐方案 A）：[中文 T9] $\rightarrow$ [英文 Multi-tap] $\rightarrow$ [数字 123]（只需勾选 3 项）。

精准模式（推荐方案 B）：[中文 T9] $\rightarrow$ [中文 Multi-tap] $\rightarrow$ [英文 Multi-tap] $\rightarrow$ [数字 123]（免去英文 T9 预测）。

1.3 快捷流跳转 (Shortcuts & Long-Press)

长按切换键（Long-press）：直接一步到位跳转到 [数字 123] 模式，再长按恢复原模式。

自动回退（Auto-reset）：在数字模式提交字符后，如开启“数字后自动切回”，则输入完数字后自动跳回上一次的中文/英文模式。

2. 对标 iWnn 的极简设置架构 (Settings Architecture)

参考 iWnn IME，将所有设置精简为 5 个核心分类，完全剥离不必要的复杂样式，所有子菜单均基于物理 D-Pad 焦点进行控制。

设置主菜单 (Settings Menu)
├── 1. 输入设定 (Input Settings)
├── 2. 输入法与按键 (Input Method & Keymap)
├── 3. 用户词典 (User Dictionary)
├── 4. 定型文/常用短语 (Phrase)
└── 5. 重置设置 (Reset)

3. 用户词典 (User Dictionary)

用户自行添加的自造词与特殊人名。

词典列表视图：展示用户自造词（拼音 $\rightarrow$ 汉字）。

添加自造词：输入拼音与对应汉字后保存至本地 SQLite 或纯文本文件。

导入/导出：支持将词典导出为 user_dict.txt，或从 SD 卡/内部存储导入。

4. 定型文 / 常用短语 (Phrase)

提供快捷插入文本功能（如邮箱地址、固定回复、常用地址）。

分类预设：电子邮箱、日常问候、个人信息。

快捷唤出：在输入界面长按 * 键或通过符号面板页签直接选择定型文插入。

5. 重置设置 (Reset)

恢复默认按键映射：清除用户自定义的 garaho_keymap.json，恢复为出厂或模板配置（防止用户把按键搞砸后无法输入）。

清空用户词库与历史：重置 RIME 学习记录与自造词。

3. 0-Touch 设置界面 UI 交互规范

针对无触摸屏设备，设置界面的交互遵循以下纯物理逻辑：

┌──────────────────────────────────────────┐
│              输入设定 (1/5)               │
├──────────────────────────────────────────┤
│ [X] 1. 中文 T9 模式                       │
│ [ ] 2. 中文 Multi-tap 模式               │
│ >[X] 3. 英文 Multi-tap 模式<  (高亮焦点)  │
│ [X] 4. 数字 123 模式                      │
│                                          │
├──────────────────────────────────────────┤
│ (▲/▼ 移动焦点，OK 键切换勾选，BACK 返回)  │
└──────────────────────────────────────────┘


绝对高亮焦点 (Focus Anchor)：当前选中项必须有高对比度背景色（如深蓝底白字或高亮边框）。

D-Pad 导航逻辑：

Up / Down 键：在上/下选项间移动焦点。

OK 键（ScanCode 23/66/ENTER）：触发勾选/取消勾选，或进入子菜单。

BACK 键：返回上一级菜单，并在退出时自动异步保存配置至 JSON 文件。
