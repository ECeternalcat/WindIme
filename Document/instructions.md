# Wind IME 使用说明书（草稿）

> 本文档为功能清单式草稿，供后续整理正式使用说明。按功能模块组织。

## 输入模式

通过 TOGGLE_LANG_MODE 键（校准的"中英切换"键）在模式循环中的模式间切换。模式循环可在 设置 → 输入设定 → 候选栏设置 → 模式循环 中自定义（至少保留一个模式）。

| 模式 | 指示标签 | 说明 |
|---|---|---|
| 中文 T9 | 中 | Rime/雾凇词库优先，逐音节分段候选 |
| 中文 Multi-tap | 拼 | 拼音逐字母输入 |
| 英文 T9 | En | 英文词库预测（自动处理大小写） |
| 英文 Multi-tap | Abc | 精确逐字母输入，用于网址、缩写等 |
| 数字 | 123 | 直接上屏数字 |

## 英文 Multi-tap 大小写（Caps 机制）

英文 Multi-tap 模式与密码等私密输入框共用的统一大小写机制。中文、英文 T9、数字模式下 Caps 键无动作。

### 绑定了 Caps 键时（设置 → 输入法与按键 → 按键校准向导，Caps 步骤可跳过）

- **短按 Caps**：仅下一个字母反向。小写状态下一字母变 大写；全局大写中下一字母变 小写（反向 Shift）。
- **长按 Caps**：全局大小写开关。再次长按恢复。长按阈值为"设置 → 输入设定 → 长按间隔"的数值。
- 同一字母的连按循环锁定同一大小写表（按 2 短按Caps后：A、再按 2 出 B，均为大写）。
- 候选栏指示标签：
  - `Abc`：全局小写
  - `aBc`：下一字母将为大写（短按后）
  - `ABC`：全局大写
  - `AbC`：全局大写中，下一字母将为小写（短按后）

### 未绑定 Caps 键时（回退：老九键混合循环）

- 连按穿越小写和大写：按 2 依次出 `a b c A B C` 再回 `a`（7/9 键为 `p q r s P Q R S`）。
- 大小写由选中的字母自带，无全局状态。
- 密码等私密输入框同样适用此回退（私密框内 `#` 键无动作；大小写仅由校准的 Caps 键或混合循环控制）。

## 候选栏（中文 T9）

三行结构：组字预览 / 候选音（拼音读音）行 / 候选词行。上下键在音行与词行间切换，左右键在当前行内移动，OK 确认。

### 候选音模式（设置 → 输入设定 → 候选栏设置）

- **现代（确认即选词）**：默认。在音行按 OK 确认读音后，光标直接跳到候选词行。
- **循环选音（逐音确认）**：整句自动分词后逐个音位确认读音。音行按 OK 锁定当前音位的读音并前进到下一个音位，末位确认后回到第一个音便于复核；音栏显示 `n/总数` 位置指示。分词边界固定，仅能选择每个音位的读音；断字不符预期时用退格重打。T9 与 Rime 引擎均适用。
- 词行候选排序：当前音节单字在前，整词候选保底可达（后置）。

### 默认候选光标（设置 → 输入设定 → 候选栏设置）

- **候选词栏**：默认。打字后光标落在候选词行。
- **候选音栏**：打字后光标落在候选音行。

## 按键校准

设置 → 输入法与按键 → 按键校准向导。逐键物理校准，全部步骤可跳过（OK/ENTER 或 → 跳过，← 回上一步，BACK 取消）。校准结果保存到用户配置槽（1-4）。

校准项：中英切换 / 符号表 / 快捷菜单 / 退格删除（可直接按机身返回键）/ 回车换行 / **大写切换 Caps** / 关闭输入法 /（Kyocera 机型）左右软键。

- 退格删除：绑定后先作退格；正文为空时再按关闭输入法；需要系统返回时再按一次。
- **退格键 + 长按收起组合（任意按键）**：校准向导中，在"长按收起输入法"步骤按下已绑定为退格的同一按键（不限返回键），会弹出确认：继续 = 该键长按变为收起输入法并取代快删，短按删除不变（短按在松键时执行删除）；取消 = 留在本步骤，可跳过或绑定其他按键。长按阈值为"长按间隔"设置值。未确认组合时，退格键长按保持快速删除。
- **机型限制（NP701KC 等）**：物理返回键为固件注入的虚拟键（无内核事件），编辑框内已有上屏文本时长按初期，固件守护进程会抢先删除 1-2 个字符——该行为完全绕过输入法（原生 iWnn 同样无法拦截），任何输入法都改变不了。空文本框或仅候选词状态不受影响。**建议将退格+收起组合绑定到其他物理按键以获得完整体验**。
- 长按【退格】+【#】5 秒：切回系统默认映射（不删除用户配置）。
- 系统默认映射只读；用户配置可切换、查看、改名、删除。

## 首次使用向导

全新安装首次打开：欢迎 → 设置默认输入法（未设置不可继续）→ 按键校准（未校准不可继续）→ 设置完毕进入设置页。向导完成前 BACK 逐页回退（欢迎页 BACK 取消，下次打开重新出现）。"清除全部设置"后向导会再次出现。

## 私密输入框（密码 / WiFi 密码等）

- 独立英文 Multi-tap / 数字输入模式，禁用联想与用户词库学习，禁用符号与短语面板。
- 左软键（或 TOGGLE_LANG_MODE）切换 en / 123。
- 大小写：同"英文 Multi-tap 大小写"一节（校准 Caps 键短/长按；未绑定时 abcABC 混合循环）。

## 检查更新与更新日志

设置 → 关于：

- **检查更新**：手动检查 GitHub 最新 release。发现新版本时弹窗显示版本号、更新日志与"去下载"（浏览器打开 APK 直链）。
- **查看更新日志**：获取最新 release 并显示日志。当前版本时为只读查看（"去下载"置灰），有新版时同更新弹窗。
- 静默自动检查：每日一次（打开设置页时触发，仅在新版本可用时提示；网络失败不提示、不占用当日次数）。
- 弹窗支持 D-pad：上下键滚动日志，滚到边界后切换按钮选中，左右键直接切换，OK 激活。

## 全屏兼容（Kyocera 机型）

Notepad（jp.kyocera.memo）、文字チェック（jp.kyocera.charactercheck）等宿主在全屏抽取模式下编辑框被清空，输入法对这些包启用全屏抽取兼容。默认列表已配置，可在 设置 → 输入设定 → 全屏兼容列表（仅 Kyocera 机型显示）添加最近使用的应用。

## 其他

- 状态指示器（候选栏模式标签）可关闭：设置 → 输入法与按键 → 显示状态指示器。
- 按键反馈（震动/声音/无）、首字母大写（英文）、长按间隔（多击字母循环与各长按功能的统一阈值）：设置 → 输入设定。
- 用户词典、定型文/常用短语、Rime 词库与部署、重置设置：设置内对应页面。
